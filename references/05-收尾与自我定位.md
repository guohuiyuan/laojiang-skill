# 05 · 收尾与自我定位

## 收尾的三个固定件

统计（`data/ritual.json`）：

- 出现「我是老蒋 / 我是一个喜欢……的 UP 主」：**94%**
- 出现「下期再见」：**84.6%**
- 出现「三连 / 关注我」：**83.9%**

标准形态：

> 我是老蒋，我是一个喜欢做什么事、喜欢分享自己观点和看法的 UP 主。如果你觉得我说的有道理或者对你有启发，请给我一个三连并且关注我，咱们下期再见。

三件套的顺序固定：**自我定位 → 求关注 → 下期再见**。顺序颠倒会很怪，因为「下期再见」必须落在最后。

---

## 自我定位为什么重要

「我是一个喜欢 XX 的 UP 主」不是客套，它在做三件事：

1. **声明边界**——我不是专家，我是一个爱琢磨这事的人。这句话预先卸掉了「你凭什么」的攻击
2. **抵消说教感**——刚 diss 完一大圈，最后一个自我定位把姿态拉回平视
3. **让人设可追踪**——XX 会变（观察社会 / 琢磨事 / 财经 / 分享观点），变化本身是内容

### XX 的实际填法（摘录）

- 「喜欢观察、喜欢思考」
- 「喜欢琢磨事儿，喜欢去跟大家分享自己的思考」
- 「喜欢观察各种社会、文化、商业现象」
- 「对世界充满好奇，喜欢做什么事，然后也喜欢输出自己感受和想法」
- 「喜欢输出自己一些知识、见解、观点」
- 「喜欢关注各种各样的问题，喜欢关注人，喜欢关注群体」

**规律**：动词集中在「观察 / 琢磨 / 输出 / 分享」，宾语是「观点 / 思考 / 看法 / 现象」。几乎不用「热爱」「深耕」「专注」这类词。

## 五种收尾方式

### A. 行动建议（最有力）

给一个普通人明天就能做的事，越具体越好。

> 「对抗战马们的最好方式就是，爱他妈谁说什么，我该吃什么还吃什么，该喝什么还喝什么，该看什么还看什么。不在垃圾议题上消耗精力，用我们的行动和消费守护我们的正常生活。」（`BV1Zx4y1D7Cf`）

> 「不要让挖坟清算成为常规武器和一种风潮，不要用它来对付敌人之外的、你们看不顺眼听不顺耳的每一个人。」（`BV1gf4y1G7F3`）

**写法**：不要写「希望大家理性看待」，要写「你该干什么」。前者是态度，后者是行动。

### B. 交给观众一个问题

不下结论，把判断权还给观众——但只在他确实没有确定答案时用。

> 「我是 88 年生人，但我是一名青年，你呢？你是什么样的青年？」（`BV1ay4y1p74L`）

> 「不知道大家听起来什么感觉，不知道你们是不是满意。」（`BV16x4y1R7MH`，调研完香水行业后）

**注意**：这一式容易被滥用成「你怎么看？评论区聊聊」。他的用法里，问题必须**扎在自己身上**——先承认自己也不确定，再问观众。

### C. 借用别人的话

整段引用，并说明为什么借。

> 「那么在视频的最后，我要用影视飓风那期视频结尾里一模一样的句子：舆论的垃圾场化已经成为既定的趋势，而传播链上的每一个人，你和我都有一部分原因。很遗憾，这就是我们共同选择的未来。」（`BV1NCCkBKEaU`）

**这是最重的收尾**，因为它把结论从一个 UP 主的观点升级为「我们共同承认的事实」。用的时候必须真的读完对方的原文，否则会被抓。

### D. 叠甲 + 收尾

先承认自己的局限，再道别。

> 「好，最后非常快速地叠个假。」（`BV1vGTXz6EHS`）

> 「其实我在结尾的部分本来我想进行一些社会观念的探讨，但是想一想还是算了，不展开太多。」（`BV1HiAZzREG4`）

**第二种更高级**：说出你本来想说什么但没说的，等于把更狠的判断交给了观众自己补。这比直接说更有力。

### E. 落回自己

把话题收回到个人经验，尤其是涉及代际、人生建议的题材。

> 「好了，就这样吧。中年人呢，要克制好为人师的臭毛病，这期就到此为止……反正我确实是非常真诚地说了上面这些话。祝我自己生日快乐。」（`BV1iM4y1F79R`）

**关键动作**：说完一堆人生建议，最后自我批评一句「好为人师」。这一步把整篇从「教导」拉回「分享」。

---

## 结尾三不要

1. **不要总结**——他几乎不做「综上所述」。结尾是**新的一句话**，不是前面内容的复述
2. **不要煽情**——不讲故事、不抒情、不用排比。情绪顶点已经在正文用掉了
3. **不要「希望这期视频对你有帮助」开头**——这句话的位置在求关注那里，不在结尾第一句

## 完整结尾模板

**模板 A（标准）**

```
[一句行动建议或判断，收束全文]
[自我定位：我是一个喜欢 XX 的 UP 主]
[如果你觉得有启发，给我一个三连，关注我]
[咱们下期再见]
```

**模板 B（重结尾）**

```
[引用 / 一句狠话]
[承认自己的位置：我也在其中]
[自我定位]
[下期再见]
```

**模板 C（收在问题上）**

```
[我本来想说什么，但没展开]
[把问题交给观众：你怎么看 / 你是什么样的 XX]
[下期再见]
```
