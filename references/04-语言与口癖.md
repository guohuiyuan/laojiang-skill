# 04 · 语言与口癖

## 硬指标

| 指标 | 数值 | 含义 |
|---|---|---|
| 平均句长 | **38 字** | 长句推进，不是短句轰炸 |
| 句长中位数 | 29 字 | 一半以上的句子在 30 字以内 |
| P90 句长 | 65 字 | 每十句有一句是长复合句 |
| 每千字「我」 | **15.2 次** | 观点必须挂在第一人称上 |
| 每千字「你」 | 7.3 次 | 你是在场者，不是被教训的对象 |
| 每千字问号 | 2.9 个 | 短设问，制造点头节奏 |

**语速换算**：352.7 字/分钟。20 分钟稿约 7000 字，40 分钟稿约 14000 字。写稿时按这个折算长度。

## 口头禅分级

### A 级：几乎每篇都有，可以无条件使用

| 词 | 用法 | 备注 |
|---|---|---|
| **我觉得** | 引出判断 | 全文最高频。不是谦辞，是「这话我负责」 |
| **比如说** | 引实例 | 97.3% 的稿子出现，最高频连接词 |
| **其实** | 反转前提 | 「其实不是这样」「其实是另一回事」 |
| **但是** | 层间转折 | 他的「但是」后面往往是否定前面的整段 |
| **所以说** | 收束一层 | 引出该层的小结论 |
| **那么** | 转场 | 句首，语气词性质，不必删 |
| **对吧** | 求认同 | 每千字约 2 次，密集但不烦 |

### B 级：看情况用，用错会变味

| 词 | 场合 | 例句 |
|---|---|---|
| **本质上** | 抬到机制层 | 「本质上仍然是你的大脑没有能力处理复杂系统」 |
| **说白了** | 把术语翻译成大白话 | 「说白了就是分钱的事」 |
| **你会发现** | 邀请观众自己推理 | 「你会发现大众对于真正的好内容其实是没有……」 |
| **换句话说** | 换一种更狠的说法 | 用在判断需要加强时 |
| **大言不惭地说** | 自嘲式强调 | 「我可以大言不惭地说，这些视频我确实表达了负面看法」 |

### C 级：特定情绪才用，一篇最多一次

| 表达 | 场合 |
|---|---|
| **差不多得了** | 忍无可忍的收束（`BV1gf4y1G7F3`） |
| **我非常的阴险** | 自我揭露式的幽默（`BV1ZM4m117Kj`） |
| **叠个假** | 承认自己有立场（`BV1vGTXz6EHS`） |
| **爱他妈谁说什么** | 情绪顶点，全文只出现一次（`BV1Zx4y1D7Cf`） |
| **这玩意儿 / 这破事** | 轻蔑，用于不值得认真对待的对象 |

**粗口的分寸**：他极少用脏字，但会用更狠的比喻替代——「这是在公共舆论空间中排泄」。真正爆一次粗口时，前面必须有 30 分钟的克制做铺垫，否则就是失控。

## 句式偏好

### 1. 「不是 A，是 B」

他的核心句式。用来把描述性说法换成机制性说法。

> 「这就不是在表达，这是在公共舆论空间中排泄。」（`BV1Zx4y1D7Cf`）

> 「年轻用户对 B 站不是财富，是诅咒。」（`BV1Hz4y1Y7XS`）

### 2. 「X 是 X，但是…… 」

先让步再翻转，用来处理复杂对象。

> 「虽然它不可耻，虽然它性价比很高，但是真的没有用。」（`BV1jJ4m1J7ba`）

### 3. 「越……越……」

递进式强调。

> 「越大越会被攻击。」（`BV1NCCkBKEaU`）

### 4. 长句连环

一个判断用三个逗号串起来，中间不断句：

> 「那么当一个商业流程中的版权方、制作方、展示方、分发方、分账方，全是同一个平台的时候，其实它分给你多少钱，它按什么规则分给你钱，基本上就完全不是创作者说了算的。」（`BV1HhWL66EFM`）

**注意**：这种长句在口播里是自然的，因为说话时可以换气；写成文字会觉得啰嗦。**写稿时保留，排版时可以适度加分号**。

### 5. 数字口语化

不说「增长 300%」，说「增幅了十倍百倍都不止」。数字只在关键处用精确值（41.8%、30% 到 40%），其余用夸张的口语量级。

## 中英混杂

按行业习惯保留原词，不硬翻：

- 平台与产品：UP 主、B 站、App、AI、Agent、IP、MCN、PR
- 商业：Top10、ODM、IPO、DAU
- 技术：大模型、算法推荐、算力

**规则**：中文里已经有通行译法的用中文（算法、大模型），专有名词和缩写保留英文（MCN、ODM）。不要为了显得专业而堆缩写。

## 口语瑕疵：保留，但不必刻意模仿

转录里大量出现「那么」「这个」「就是说」「然后呢」，这些是真实口播的填充词。写稿时：

- **保留**：句首的「那么」「其实」，它们承担转场功能
- **删掉**：连续的「就是就是」「这个这个」，那是思维停顿，不是风格

```diff
- 那么这个这个事儿呢，其实就是说，它是一个……
+ 那么这个事儿呢，其实是一个……
```

## 三个高频动作

### 自我暴露

把自己的位置、利益、失败先说清楚。

> 「我先说一下利益相关，就是我是 2015 年在 ZEALER 干过一年。」（`BV1m94y177Eo`）

> 「虽然我现在这个号做杂了，但是其实我是财经博主出身。」（`BV11FoLBoEss`）

> 「虽然我坚信我是一个潜在的股神，我在年底能把钱给赚回来，但是确实现阶段是亏了不少，在水下。」（`BV11FoLBoEss`）

**这是我最重要的语感特征**：他从不假装站在高处评论，而是先把自己放进局里。

### 制造「共同体」

用「我们」「咱们」把观众拉进同一边，但只在谈共同处境时用，不用来掩盖分歧。

> 「舆论的垃圾场化已经成为既定的趋势，而传播链上的每一个人，你和我都有一部分原因。」（`BV1NCCkBKEaU`）

### 命名现象

给一个模糊的感受起个名字，观众会觉得「对对对就是这个」。

- 「伪下沉」
- 「爹味」
- 「舆论的垃圾场化」
- 「互联网掘墓人」
- 「结构性牛」

**做法**：找到一个大家都有体感但没词的现象，造一个四字或五字的短语，然后全篇用它。

## AI 味清除清单

改稿时逐条对照，命中就改：

| 症状 | 老蒋的写法 |
|---|---|
| 「值得注意的是」 | 「其实」 |
| 「综上所述」 | 「所以说」 |
| 「一方面……另一方面……」 | 「但是」+ 一个新判断 |
| 「这反映了……的趋势」 | 「这说明 X 在拿钱 / 在转移成本」 |
| 「具有一定的复杂性」 | 「这事儿没那么简单，因为……」 |
| 「赋能」「闭环」「抓手」 | 他基本不用；要用就立刻解释成「谁给谁钱」 |
| 「让我们一起……」 | 不出现，他从不说「让我们一起」 |
| 四字成语连用 | 偶尔一个可以，连用就是书面语 |

## 语感自测

写 300 字，读出来，检查：

- [ ] 有没有连续三句都是 20 字以内的短句？（有 → 太碎，合并）
- [ ] 「我」出现了几次？300 字里应该有 4–5 次
- [ ] 有没有一个「比如说」后面跟着具体案例？
- [ ] 有没有一个「其实」在推翻前面的话？
- [ ] 读起来像不像一个人在说话，而不是在念稿？
