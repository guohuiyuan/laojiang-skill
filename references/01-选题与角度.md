# 01 · 选题与角度

**选题的第一道筛选**：这件事有没有「大众共识」可以反驳？没有共识的题目，反常识就没有着力点，只能写成科普。

## 三类题源与命中率

### 1. 舆情事件（占比最高）

触发方式：热搜、朋友圈刷屏、同行翻车。

关键动作不是复述事件，而是**找出大众情绪里的逻辑漏洞**。农夫山泉那期的做法是：先承认「这些视频对某些事物我确实表达了负面看法」，再划出边界——「但是它们是守住的底线……你简单粗暴地说农夫山泉是卖国企业，这就不是在表达，这是在公共舆论空间中排泄」。

这是他的标准动作：**先站到大众多数情绪的同侧，再指出它越界的那一步**。如果一上来就反对大众，稿子会变成说教。

### 2. 平台/行业结构

这类题目的价值不在「发生了什么」，而在**规则变了之后，谁的成本被转移了**。

- 短剧：「当一个商业流程中的版权方、制作方、展示方、分发方、分账方全是同一个平台的时候，它分给你多少钱，基本上完全不是创作者说了算的」（`BV1HhWL66EFM`）
- B 站：「B 友们狭隘单一的价值观导致 B 站逐渐崩坏的舆论环境，并且进一步导致 UP 主商业化还有 B 站商业化的难题」（`BV1Hz4y1Y7XS`）
- 手机：「万亿级别的赛道居然变成了一个没有细分品类的领域」（`BV1tg4y1M7kw`）

**判据**：你能不能说出一个「本来应该这样，实际却那样」的结构性反常？说不出，就是资讯。

### 3. 读者提问（38.3% 的稿子有明确触发）

「有人私信我」「源自一个我和朋友之间的打赌」「上期视频发出后收到很多反馈」。

这类题源的隐藏价值：**提问者自带困惑的具体形态**，你不必猜读者在想什么。写的时候把这句困惑原样放进开头，比自己编一个设问有力得多。

## 角度：反常识的四种造法

标题统计显示，38% 的题目含否定/反常识词（不、没、别、难、错、假、崩、凉、伪）。

### A. 把褒义翻成贬义

- 「年轻用户对 B 站**不是财富，是诅咒**」（`BV1Hz4y1Y7XS`）
- 「下沉内容崛起：一场**双向奔赴的伪下沉表演**」（`BV1RY4y1d7L6`）

做法：找到大家一致称赞的对象（年轻用户、下沉内容），问「它真的带来了它承诺的东西吗」。

### B. 把个别现象抬成结构问题

- 「**每个人都**应该掌握的快速调研法」（`BV1pF411f7yD`）
- 「你**和勇哥视频里那些神人没啥区别**」（`BV1YBrsBZEcT`）

做法：先讲一个极端个案，最后一步把镜头转回观众——「你们也一样，只是程度不同」。这一招在结尾用最有杀伤力。

### C. 用数字把感受变成事实

28% 的标题含数字。最典型的是「字节拿大结果，你拿大红果」（`BV1HhWL66EFM`）——「字节系产品在中国 top50 的 App 中总时长份额占到 41.8%」，一个数字就把「刷手机太久」的模糊感受变成产业事实。

做法：找到一个可核查的比例，然后问「这 41.8% 是谁的时间、换来了什么」。

### D. 自嘲式降维

- 「巴菲特也错过了科技牛，**所以我 = 巴菲特**」（`BV1EfTe6jEVe`）
- 「好消息：龙虾能帮忙炒股，**坏消息：我不听劝**」（`BV11FoLBoEss`）

做法：先抛一个正经判断，再用一句自嘲把姿态压低。**自嘲是为了让后面的硬判断不被当成说教**。

## 标题的六种形态（按实测占比）

| 形态 | 占比 | 例 |
|---|---|---|
| 否定 / 反常识 | 38% | 「年轻用户对 B 站不是财富，是诅咒」 |
| 含数字 | 28% | 「34 岁中年 up 主的几个人生建议」 |
| 【系列标】 | 22% | 「【解构B站2】」「【品类战争】」 |
| 疑问句 | 19% | 「每天看罗振宇能自我提升吗？」 |
| 含冒号（主副标题） | 18% | 「饭圈观察（上）：饭圈演变成今天的形态，有微博一半功劳」 |
| 第二人称 | 8% | 「别笑，你和勇哥视频里面那些神人没啥区别」 |

**组合用法最常见**：「事件/对象 + 冒号 + 我的判断」或「判断 + 【系列名】」。系列标的意义是给老观众一个回收理由，不指望它吸引新观众。

## 选题自检清单

写之前逐条过，任何一条答不上就换角度：

1. 这件事大众的默认解释是什么？能用一句话说出来吗？
2. 我的判断和默认解释的差异在哪一点？这一点有没有证据（数据/机制/当事人位置）？
3. 我在这件事里的位置是什么？有没有需要交代的利益？（有就写进开头，别等被扒）
4. 这个判断会不会伤到具体的人？如果会，我准备用哪种方式承担（点名/不点名/只谈机制）？
5. 结论对观众有什么用？如果只是「知道了」，那这期就是资讯，不是评论。
