# 03 · 论证推进

## 主干：分层，而不是分点

88.6% 的稿子有明确的「第一点 / 第二点」或「第一层 / 第二层」，88.6% 出现「三句话 / 三点」。

但要注意他和「三点式」鸡汤的区别：**他的点是递进的，不是并列的**。并列的三点是清单，递进的三层是解释。

典型递进：

> 第一层是电影的表达方式，也就是外壳和真正所表达情绪之间的一种隔离……（`BV1AZ421m7ZY`）
>
> 那好，第三层呢，第三层是，地狱梗其实是一种贬损性的幽默，那么凡是贬损性的幽默里面都藏着一些攻击性和非常原始的恶意。（`BV1ZM4m117Kj`）

每一层都在回答「上一层的现象为什么会发生」。

### 五层推进模型

| 层 | 回答的问题 | 缺了会怎样 |
|---|---|---|
| **1 现象** | 大家看到的是什么 | 观众不知道你在说什么 |
| **2 机制** | 为什么会这样（规则、成本、激励） | 变成情绪输出 |
| **3 代价** | 谁在承担这个机制的后果 | 变成行业分析，与观众无关 |
| **4 受益** | 谁从这个结构里拿走了钱 / 权 | 显得天真，像在喊口号 |
| **5 个人** | 普通人该怎么应对 | 没有落点，看完白看 |

不是每篇都要五层，但**2 和 3 不能少**。少 2 就是牢骚，少 3 就是软文。

### 实例：字节那期怎么走完五层

- **现象**：「字节系产品在中国 Top50 的 App 中总时长份额占到 41.8%」（`BV1HhWL66EFM`）
- **机制**：「当一个商业流程中的版权方、制作方、展示方、分发方、分账方，全是同一个平台的时候，其实它分给你多少钱，它按什么规则分给你钱，基本上就完全不是创作者说了算的」
- **代价**：「普通人只能够过一下瘾，你能够把你的幻想世界给做出来，然后给你的朋友看」
- **受益**：平台拿走时长份额，创作者拿到的是被算法决定的曝光
- **个人**：「如果你使用它的方式是它只能给你提供单纯的刺激的话，那我相信大家都有这样的感受」

## 四种硬料

### 1. 类比（87.2%）

类比的作用是把**陌生的机制翻译成熟悉的经验**，不是让文章好看。

> 就像汤姆总想抓住 Jerry，惩罚他但是不想弄死他。（`BV1vGTXz6EHS`，讲平台和头部创作者的关系）

> 这个澡堂呢，看上去只是洗澡的地方，但其实是给这些暂时没有办法进入主流的人群一个庇护所。（`BV1Pz4y1k7pu`）

> 嘉然虽然只有一米出头，但是她的形象是这么的光辉。（`BV11T4y1f78Q`）

**判断类比是否合格**：把类比去掉，机制还讲得通吗？讲得通说明类比只是装饰；讲不通说明它在承重。

**他偏爱的类比源**：动画（汤姆和杰瑞）、日常消费（澡堂、香水小样）、身体经验（挨饿、囤粮）、商业史（硅谷车库）。

### 2. 实例（97.3%）

「比如说」是他最高频的连接词。**每一个抽象判断后面几乎都跟着一个具体案例**。

> 很多人可能会觉得创作激励自古以来在 B 站就有，而且好像是一种行业惯例，但其实不是。（`BV1oC411h7L5`）

**写法**：抽象句 → 「比如说」 → 一个有名有姓的例子 → 「但如果你只看到这些，就到此为止，那你根本就没有搞懂这个行业的核心逻辑」。

最后这句是关节：**例子不是终点，是下一层的台阶**。

### 3. 数据（用在关键处，不铺满）

他不做数据密集型内容，但关键位置一定有硬数字：

- 「41.8%」（字节总时长份额）
- 「100 个人里只有三四十个知道肖战」（`BV1vE411K7wH`，讲流量的真实覆盖面）
- 「电池成本大概占 30% 到 40%」（`BV1XXk7YUEsS`，讲新能源车成本结构）

**用法**：一个数字配一个「所以」。「41.8%」本身是资讯，「41.8% 意味着你清醒的时间里有一半不属于你」才是论点。

### 4. 设问（94.6%）

短促、密集、用来制造点头节奏：

> 对吧？ / 不是吗？ / 为什么呢？ / 凭什么？ / 怎么会？

统计上每千字 2.9 个问号。**注意**：这是口语里的「对吧」，不是书面语里的设问段。他的设问从不自问自答一整段，问完立刻往下讲。

## 三个必须会用的动作

### 动作一：预设反对，然后拆掉

> 那说到这里呢，你可能觉得我是赞成大家玩地狱梗的啊，但是不对啊，因为我是一个媒体人啊，我非常的阴险。（`BV1ZM4m117Kj`）

> 但是抱歉了，我并没有这样的信心。（`BV1gf4y1G7F3`）

**模板**：「你可能觉得我要说 X。但是不对。」——先说穿观众的预期，再翻转。这比直接给结论有效，因为它替观众完成了「我已经猜到你要说什么」的满足感，然后打掉它。

### 动作二：叠甲（20.1% 明确出现）

> 这个可能有点身边统计学，但是我身边确实是这样，接受你们的反驳。（`BV1ZM4m117Kj`）

> 最后非常快速地叠个假。（`BV1vGTXz6EHS`）

叠甲不是怯懦，是**主动交出弱点来换取信任**。承认「这是身边统计学」之后，后面那个判断反而更可信。

**用法**：只叠真弱点。把明显的漏洞自己说出来，把不明显的留给对手——这不叫坦诚，这叫控场。

### 动作三：把镜头转向观众

在论证快结束时，把前面属于「他们」的问题，变成「你」的问题。

> 别笑，你和勇哥视频里面那些神人没啥区别。（`BV1YBrsBZEcT`）

> 这件事细想下来你是很奇怪的，因为你如果花五千块钱请别人喝酒……（`BV1HiAZzREG4`）

**这一招的伦理边界**：转向之后必须给出口，不能只是羞辱。他的做法通常是「我们也一样，所以可以试着用理性去克服」。

## 结构模板（20 分钟稿）

```
[开篇：判断 + 为什么现在说]                     约 1 分钟
[第一层：现象——一个具体到能看见细节的事]        约 4 分钟
[第二层：机制——规则怎么运作，钱怎么分]          约 6 分钟
   └ 中间插一个类比 + 一个「比如说」
[第三层：代价——谁在承担，承担成什么样]          约 4 分钟
   └ 这里放预设反对：「你可能觉得……但是不对」
[第四层：我自己的位置 / 我为什么这么看]         约 2 分钟
   └ 叠甲放在这里
[收尾：判断 + 对普通人的一句建议]               约 1 分钟
```

## 空洞检测

写完通读一遍，逐段问：

1. **这段能被替换成任何人的观点吗？** 能，就是空的
2. **这段有没有一个「因为」？** 只有「是什么」没有「为什么」，就是描述
3. **这段的类比能不能删？** 能删说明它没在承重
4. **这段有没有交代「谁付钱」？** 所有商业评论最终都要回答这个问题

如果四问有三问答不上，这段要重写。
